# JARVIS-AI-Voice-Assistant
JARVIS is an AI-powered voice assistant built with Python that listens to voice commands and performs day-to-day tasks automatically. It can search Google and Wikipedia, play YouTube videos, send WhatsApp messages and emails, open system applications like Chrome, Notepad, Spotify, and Camera, play local music, and fetch real-time data like current time and public IP address. Built using pyttsx3 for text-to-speech, SpeechRecognition with Google Speech API for voice input achieving 95% accuracy, pywhatkit for WhatsApp and YouTube automation, OpenCV for webcam access, and pygame for music playback. The assistant greets users based on time of day and responds conversationally to every command. Designed to reduce manual effort by 60% for routine daily tasks.
